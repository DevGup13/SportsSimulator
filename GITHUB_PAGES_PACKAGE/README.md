# Sports Simulator — portable beta

1. Create a GitHub repository and upload this package's contents to its root.
2. In Settings > Pages, select GitHub Actions as the deployment source.
3. Enable Actions and grant workflow read/write permissions.
4. Run the "Sports Simulator site and scheduled fixture refresh" workflow manually.
5. Verify the Pages URL and the fixture, research, and release pages.
6. Verify a subsequent scheduled run; GitHub schedules can be delayed.

The workflow refreshes ESPN fixtures only, not model probabilities.
Research forecasts remain experimental static snapshots.
The original Drive files are unchanged.
